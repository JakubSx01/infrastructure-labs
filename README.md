# Infrastructure Troubleshooting Labs

This repository contains hands-on IT infrastructure labs focused on
system administration, networking, DevOps and cybersecurity.

The goal is to document practical troubleshooting scenarios performed
in controlled laboratory environments.

Each completed lab may include:

- problem description
- environment and technologies used
- troubleshooting process
- commands and tools
- root cause analysis
- remediation
- verification
- lessons learned

## Areas

### Windows Server

Labs related to Windows Server administration, Active Directory,
Group Policy, DNS, DHCP, PKI and Windows troubleshooting.

### Networking

Labs covering switching, routing, VLANs, DHCP, DNS, firewalls,
network troubleshooting and network services.

### Linux

Linux system administration and troubleshooting, including systemd,
services, networking, storage, permissions, logs and web services.

### DevOps

Practical labs involving containers, Docker, Kubernetes, CI/CD,
monitoring and infrastructure troubleshooting.

### Security

Defensive security and incident-response labs involving Windows and
Linux systems, logs, suspicious activity, access control and
security monitoring.

## Environment

Labs may be performed using:

- virtual machines
- Proxmox
- VMware
- Cisco Packet Tracer
- SadServers
- TryHackMe
- Hack The Box Academy
- Killercoda

## Disclaimer

All scenarios are performed in controlled laboratory or training
environments.

This repository does not contain confidential data, credentials or
production infrastructure configurations.
